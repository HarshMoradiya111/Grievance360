  | Metric | How it is computed |
  |--------|--------------------|
  | Total assigned | COUNT complaints WHERE assignee = staff |
  | Resolved | COUNT WHERE status in (Resolved, Closed) |
  | Resolution rate | Resolved / Total × 100 |
  | SLA breaches | COUNT WHERE deadline < now AND status open |

  | Satisfaction proxy | (Resolved − Reopened) / Resolved × 100 |

## Database Engine Portability

The project uses `db.py` as an abstraction layer:

- All queries use `%s` placeholders (MySQL style).
- `_SQLiteCursor.execute()` rewrites `%s → ?` on the fly for SQLite.
- All date arithmetic is in Python — no `DATE_ADD`, `DATEDIFF`, or engine-specific functions in SQL.
- Switch engine: change `DB_ENGINE = "mysql"` in `config.py` and supply MySQL credentials. Zero query changes needed.
